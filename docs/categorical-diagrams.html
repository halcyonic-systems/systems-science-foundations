Non-Faithfulness Witness (Concrete Example)

graph LR
    subgraph "BtcState: bs = {u3, u7}"
        BS1["bs = {⟨val=3, addr=0⟩, ⟨val=7, addr=0⟩}"]
    end

    subgraph "Two distinct endomorphisms"
        TX1["f₁ = [tx₁]
consume u3, produce u3"]
        TX2["f₂ = [tx₂]
consume u7, produce u7"]
    end

    subgraph "EthState: collapse(bs)"
        ES1["addr0 ↦ 10"]
    end

    BS1 -->|"f₁ : bs ⟶ bs"| BS1
    BS1 -->|"f₂ : bs ⟶ bs"| BS1
    BS1 -->|"collapseFunctor.obj"| ES1

    TX1 -->|"collapseFunctor.map"| ID["id : collapse(bs) ⟶ collapse(bs)
(unique — thin category)"]
    TX2 -->|"collapseFunctor.map"| ID

    style BS1 fill:#fff3e0,stroke:#e65100,stroke-width:2px
    style ES1 fill:#e3f2fd,stroke:#1565c0,stroke-width:2px
    style TX1 fill:#ffcdd2,stroke:#c62828
    style TX2 fill:#ffcdd2,stroke:#c62828
    style ID fill:#c8e6c9,stroke:#2e7d32
The witness: f₁ ≠ f₂ (different transaction lists: [tx₁] ≠ [tx₂]) but collapseFunctor.map f₁ = collapseFunctor.map f₂ (both map to the unique endomorphism in the thin Eth category). If collapseFunctor were Faithful, map would be injective, forcing f₁ = f₂ — contradiction.
Interpretation: UTXO-land has strictly more transactional information than account-land. Consuming and reproducing u3 vs. consuming and reproducing u7 are distinguishable operations on the UTXO set, but invisible at the balance level.
